# AgentForge 全局视觉与设计系统

更新日期：2026-10-02

## 1. 品牌

主品牌名称：

```text
AgentForge
```

中文产品描述：

```text
企业级 AI Agent 平台
```

顶部品牌区建议结构：

```text
[图形标] AgentForge
         企业级 AI Agent 平台
```

## 2. Logo 方向

Logo 必须基于 AgentForge 自身含义设计，不使用需求附件中的示例 Logo，也不照搬 OpenAI、Dify 或其他产品标识。

当前推荐方向为“AgentForge 节点字标”：

- 使用抽象字母 `A` 作为主体。
- 三个连接节点代表 Agent、Knowledge、Tool / MCP。
- 中心汇聚点代表 Agent Runtime。
- 一条延伸轨迹代表 Trace。
- 使用克制的蓝紫色，不使用大面积复杂渐变。
- 图形在 24px 侧边栏尺寸、顶部导航和 favicon 场景中仍需清晰。
- 避免通用 AI 大脑、机器人头像、聊天气泡和旋涡符号。

Logo SVG 尚未制作，需在用户确认最终图形方案后单独完成。

## 3. 视觉风格

- 浅色企业后台。
- 页面大背景使用浅灰色。
- 主内容、列表项和功能区使用大面积白色 Card。
- 蓝紫色作为 AI 品牌色、焦点色和主要交互色。
- Card、输入框、按钮采用适度圆角。
- 阴影轻微，主要依靠边框、留白和层级区分区域。
- 极少使用渐变，仅允许在品牌标识或 AI 运行状态中轻量使用。
- 风格参考 Linear、OpenAI、Dify，但不得直接复制。
- 不做传统 Java 后台式的密集表格和强边框页面。
- 中文界面，信息密度适中，专业、克制、清晰。

## 5. 通用组件规范

- 页面标题区统一包含标题、副标题和主要操作按钮。
- Loading 使用 Skeleton，不使用大面积全屏 Spinner。
- 成功和失败反馈使用 Toast，不使用浏览器 `alert`。
- 危险操作使用确认 Dialog。
- 状态使用克制的 Badge，避免大面积高饱和色。
- 空状态包含说明和一个明确的下一步操作。
- 表单提交期间按钮进入 Loading 并避免重复提交。
- 主要面向 1440px、1280px、1024px 桌面宽度。
- 移动端只保证基本不崩坏，不单独设计移动端产品体验。

## 6. 技术约束

- Vue 3 Composition API。
- 使用 `<script setup lang="ts">`。
- TypeScript 严格类型，避免大量 `any`。
- 页面、组件、类型、API、Mock 和状态管理分层。
- Mock 数据不能散落在 Vue 页面中。
- 真实接口必须通过统一 Axios 实例和 API 模块访问。
- 不修改与当前页面无关的模块。
